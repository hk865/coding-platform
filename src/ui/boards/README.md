# src/ui/boards/：工作副本画板

这一层放冻结原型（`docs/ui-reference/workbench-2026-10/`）的工作副本和一份 `kit.css`。构建时同名有工作副本就用工作副本，其余仍取冻结原件；冻结后新加的设置页只有工作副本。模板、类名和布局照原型，只换数据层（`src/ui/boot.ts` 和 `src/ui/adapters/`）。

## 文件

| 文件 | 负责什么 |
| --- | --- |
| `Settings.dc.html` | 设置页（C1、C3–C6）：页头“返回工作台 / 设置 / 项目名 / 深浅切换”，左侧分组导航只列本批有内容的“工作区与权限”“自动化与规则”“运行上限”三组；快照读不出时整页一行原因加“重试”。工作区组每个工作区一行（名字、路径、两个勾选），勾选改变即写 `workspaces/access`，`accessFixed` 的两个勾选灰掉并写原因；同一组下面按工作区列 `checks`（id、命令、查哪些任务、来源）和“撤回”（先出行内确认），`withdrawnChecks` 收在“已撤回”折叠里，撤回进入“已保存，尚未生效”时这个折叠强制打开，让提示和“重试”看得到。自动化组画“结构改动”一块：两个 `.mode` 盒形切换（自动 / 出卡问我，默认值旁写“· 默认”）读当前项目的 saved/defaults，写 `structural-approval/save`；运行上限组画“命令审查线”一块：现在生效的分钟数、整数输入、保存和“已保存”，写 `command-review/save`，空回默认、非正整数在本地标红不发。两块写成功都用回答里的新快照重画，失败写这一块的中文原因（不直接上屏 Host 原句）；Host 回“已保存、尚未确认”时先重读一次快照再画，那一行/那一块写“已保存，尚未生效”加“重试”，重试重发同一次写。快照读不出只盖整页（原因加“重试”），不盖已读数据。入口在六块有左栏的板的 `.rail-foot`，带来源页的全部查询参数，`Esc`/“返回工作台”回原页。第 2 批的组和占位本批不画。 |
| `Main.dc.html` / `Plan.dc.html` / `Decide.dc.html` / `Done.dc.html` / `Member.dc.html` / `Chain.dc.html` | 原有工作副本；六块的 `.rail-foot` 在深浅切换左边有齿轮图标加“设置”，链接到 `Settings.dc.html`，带来源页的全部查询参数。 |
| `ArchOverview.dc.html` / `Goals.dc.html` / `TaskMap.dc.html` | 原有工作副本，没有左栏的“设置”入口。 |
| `kit.css` | 冻结原型的样式表工作副本；设置页只用其中的颜色变量和 `.row`，不新增 kit 规则。 |
