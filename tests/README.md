# 测试夹具清单

写测试前**先在这里找夹具**：找到就直接用；夹具缺一个公开步骤，**报给 lead**，不要在测试里手写事实、补记录或绕过 owner。测试规则（允许什么、禁止什么、怎么判）见 `tests/RULES.md`。

`tests/helpers/` 按主题分组，每组内按文件名排序。每个 helper 一行：给出什么前置状态、走哪些公开步骤、谁在用。标「冻结」的夹具只能在末尾追加导出，已有内容不能改。
