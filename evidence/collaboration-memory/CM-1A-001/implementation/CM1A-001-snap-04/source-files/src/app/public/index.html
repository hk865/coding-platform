当前验收边界
此 GUI 已提供真实开发与探索运行、模型配置、文件引用，以及样例任务的查询和证据查看。真实任务的语义问询、完整角色协作、设计审批、审阅返工、中断续跑和正式完成的整条操作链仍待接通与验收。
验收材料应包含版本与工作区差异、命令回执、事件游标、任务与 Run 标识、模型和预算、代码变更、测试输出及复核结论。另做单长会话对照，比较时间、令牌、返工和人工干预次数。
