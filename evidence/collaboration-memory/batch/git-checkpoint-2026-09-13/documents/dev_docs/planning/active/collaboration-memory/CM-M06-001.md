## 实现约束与待收敛字段

- any是可选材料等待方式，不是完成策略，不接纳或替代任何正式Verification/Evidence，不弱化required义务。条件只引用本Work有权读取的canonical报告；合格判定和精确获胜版本由真实Control/Ledger事实决定，不能由模型传入satisfied或由缓存猜测。
- 模式、获胜条件与Delivery选择需贯通Host → Control → 原子wait/admission fold → Ledger两个适配器 → Dispatch/Context，不能只给类型加any。all旧数据和未传mode的旧调用保持兼容。
- 当前buildSuccessorCommit把所有条件标成满足，新增any时必须记录实际满足条件，不能制造未到报告；同时调整真实admission材料解析，不能因另一个可选报告未到而阻塞。
- 订阅取消只影响未来路由；已投递材料是否可读仍由明确当前授权决定。source pin/撤权检查保留，不从订阅缓存推导正文权限。
- 重放保持固定horizon和每页512事件prefix上限（非累计512），跨topic同源位置排序、部分页恢复与边界拒绝要有定向证据。
- ReadModel负责可重建展示，暴露sourceCursor及不完整/落后状态；不能把drive内存计数或工具success当持久事实。不得新增第二调度循环。
