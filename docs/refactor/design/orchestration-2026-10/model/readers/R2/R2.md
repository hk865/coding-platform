### R2-1

### R2-2
- 给定：上一个 Turn 在 Kernel 里没有终态，原 Session 退役。
- 动作：平台为接着做同一个任务建一个新 Session。
- 按设计的结果：新 Session 的来历记“接续”，原因写“中断”，并带入原 Session 已完成的历史。
- 依据：
  - DESIGN:674 | 都写“接续”，并写明原因：中断、旧的已归档、坏了、角色不对
  - DESIGN:687 | 接续在一个新 Session 里跑，新 Session 带入原 Session 已完成的历史。
- 状态：靠推断
- 以后的模型可能这样读错：可能把它只当新线，不沿来历认成原线的接续。
- Codex 模糊点：无

### R2-11
- 给定：Host 重启了；没有 K 片。
- 动作：平台核对中断时看 Kernel 里上一个 Turn 有没有终态。
- 按设计的结果：有终态（例如让出执行等回复）就在原 Session 接着做；没有终态（安全点暂停中重启、Host 中断、人工认定时还没结束）就原 Session 退役、结论码 kernel_turn_open，接续在一个新 Session 里跑并带入已完成的历史。
- 依据：
  - DESIGN:686 | 上一个 Turn 在 Kernel 里没有终态时（安全点暂停中 Host 重启、Host 中断、人工认定时 Turn 还没结束），原 Session 退役，结论码 kernel_turn_open。
  - DESIGN:688 | 上一个 Turn 已有终态时（例如让出执行等回复），在原 Session 接着做。
- 状态：靠推断
- 以后的模型可能这样读错：可能不看终态，一律新建 Session，把让出执行的回复丢掉。
- Codex 模糊点：无
