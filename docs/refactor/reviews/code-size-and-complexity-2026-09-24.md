## 3. 函数长度与分支复杂度近似

使用现有 Node 24.21.0 与本地 TypeScript AST，不安装依赖。统计有函数体的声明、表达式、箭头、方法、构造器及 getter/setter，包含回调；不计只有签名的声明。当前生产有 616 个 TS/JS 文件、7,787 个函数，测试有 637 个 TS/JS 文件、11,117 个函数；两个快照均无解析失败。

**分支评分**每函数从 1 开始，对 if、各类循环、非 default case、catch、三元表达式及 `&&` / `||` / `??` 各加 1；参数默认表达式也计入。嵌套函数单独评分，不重复计入外层。它没有构建完整控制流图，不计可选链、隐式异常路径和顶层分支，因此称为“语法分支近似”，不等同于正式圈复杂度，更不等于算法 Big-O、认知复杂度或运行耗时。

**函数长度**是首尾语法位置的包含行数，去掉前导注释；外层函数长度包含其嵌套函数所在行，因此不能把各函数长度相加当作代码总行数。单行箭头也算函数。P50/P90/P95 使用最近秩 `ceil(n × p)`；HTML 中内嵌 JS、CSS、Python、SQL 不做 AST 分支测量。
