## 契约、测试与实现

依据[原任务](../tasks/R2e-1-text-read-compare.md)，验收既有 text capture、精确 working_tree/capture 读取、paths/text 查询、同范围比较及真实 project_source 工具入口。原有 16 项冻结测试通过；GPT‑6 Sol 补充的两项边界测试经主 Agent 审阅和复现后交 dsh。

主审撤销了一个错误要求：符号链接原本不在 text 声明域，不能以显式符号链接 prefix 的空结果认定漏项。最终测试使用真实可读普通文件 `foo:bar.txt`，证明 Kernel 许可并可读、上层却静默过滤后声明 complete 的缺陷。现改为已授权且 prefix 内无法表示的路径使整次捕获明确 unsupported；保留现有跨平台路径约束，不发布半份结果、不占住捕获槽。

比较新增清单大小差的容量下界：最终变化数至少为两个清单的文件数差。下界已超过上限时，无需构造完整差异即可拒绝。一般比较仍须扫描清单以确认重命名的全局内容唯一性；此优化不宣称消除了所有完整扫描或所有中间分配。未减少权限、来源和作用域核对。
