# DSH 分级测试（2026-10-06 晚至 10-07 早）

**为什么做。** HANDOFF 决定 32：任务 D（WorkGraph 拆分）交给本地 DSH 执行之前，先测它在本仓库上的上限，并据此改进任务书的写法。用户补充了三点：DSH 很快，pro 写代码可能不如 flash，flash 时好时坏；还提醒反馈要给出问题位置和思路。测试据此安排。

**结果一句话。** 没有找到规模和难度上的上限：57 次运行里，每一级都有一种写法第一次就通过，最大的一级是在 bfb6075 上做完整个任务 D（搬 17 个文件、改 157 个文件，约 6 分钟）。出错的地方在任务书怎么写规则，而不是任务多大。结论和写法已经写进 [DSH-WORKFLOW](../../../DSH-WORKFLOW.md) §1 和 §6。
