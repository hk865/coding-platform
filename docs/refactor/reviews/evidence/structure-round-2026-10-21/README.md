## 怎么证明行为不变

结果副本，先让基线跑两次结果一致，再拿结果和基线逐字节比；对不上的地方要么修，要么写明为什么无法固定。

  不变）。

  对照表），Codex 核过。
- **D3a：** 渲染器 1,968 次调用重放，0 差异；308 个边界输入，0 差异；规划指引、Query 最终输入和两个时点的工具，22 个文件
  405 条，原始字节相同；返工 1 的修正在 K3 审查（有、无条目）和提案上逐字节相同。
