# 2C 片的执行证据（2026-10-15）：状态词、工作线左栏、置顶、悬停卡和节点详情

**是什么。** [2C 片规格](../../../design/orchestration-2026-10/slices/slice-2C-SPEC.md)（L1–L17、§3 的各表、§5 的 LE1–LE7 和 2C-01…2C-40；冻结时的限定见 §15，施工和验收中的限定见 §16）：
- 线的状态词（含已做完、已退役和归档后的标签）、左栏的词和三个计数，读时算、不存；
- 活跃线一次全部返回、已排好序；已归档的线分页；单条线和它的分节（参与、消息、副本、执行、对话）；
- 置顶（存在工作区记录上，一次可加可删）；
- 悬停卡数据（`graph/hover`）和节点详情（`graph/detail`：同文件、同模块的风险，异常锚点，参与过的线）；
- 七个路由，8 个新索引和存储层的计数读口；
- 施工中查出并改掉的三处已有行为：Kernel 存储删掉、弄坏的线怎么退役（新行 SES-19a）、人归档 RUN-24 退役的线时写异常锚点、复用的 Session 领取任务时开负责关系（SES-02）。

- A8-3n 跟着第 6 轮第 10 项改断言；
