# 本机工作区与模型设置 · 2026-09-29

状态：**本批集成、浏览器与常用启动器核验完成**。后端 10 文件、UI 4 文件及共享 DTO 已精确导入，不宣称整个 MVP 完成。

## 使用

1. 点击导航左下角“设置”。工作区页可输入本机绝对路径、浏览子目录或返回上一级，再选择“打开此文件夹”；这使用 Host 本机目录，不上传目录副本。
2. 可新建项目，或把目录作为工作区加入已有项目。同一项目的多个工作区分别可选，切换保留各自对话草稿与 Session。空 Host 也能从此打开第一个目录。
3. 文件写入和命令执行默认关闭。需要时显式开启；命令执行依赖文件写入授权。
4. 模型页支持新增/编辑 DeepSeek Chat、OpenAI Responses 配置，随后为工作区选择已配置模型。API key 不回填；留空保留已有值。DeepSeek 的 thinking/reasoningEffort 使用实际配置字段。
5. 配置保存不发模型请求。已开始 Run 继续使用固定配置；后续新运行使用更新后的模型选择。

## 实现边界

- 目录、模型配置属于 Host 本机设置；不增加 WorkGraph 事实 owner，不改原型三栏、双图或 Session renderer。
- typed key 写入本机私有文件，不返给 UI、不写入仓库或浏览器持久存储；可沿用 provider 原环境密钥来源。界面仅显示是否已配置。
- bootstrap 更新保留既有 scope 状态，仅为新增工作区初始化状态；关闭设置后的迟到响应不抢当前对话。
- 读取/保存错误显示实际原因。保存成功但 profile 刷新失败时保留已保存事实并提示刷新错误，不伪造回滚。
- 本批尚未重测真实模型连接；配置保存成功不等于模型调用成功，也不代表整个 MVP 完成。
