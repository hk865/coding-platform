## 边界与施工

仅改前端四文件，复用既有 handler、owner、Kernel、身份/分页/历史/草稿/CAS/命令句柄。不得引入新聊天存储、调度器、图事实、角色默认实例或模拟数据。不得以 CSS 隐藏旧长页面冒充重建信息结构，也不复制原型示例内容。旧高级诊断可留在明确设置/诊断入口。

沿既有两阶段 DSH：第一阶段冻结显示状态/组件接口与现有数据映射后停止；主审核对原型再实施整体 UI。此批不新增镜像 HTML 测试；原有行为测试、类型与构建足够，必要消费者断点才补真实行为检查。浏览器按原型操作路径逐项对照，尤其默认信息量、直接入口、连续图、独立详情滚动、草稿/选区/标签页保留。无需为纯前端返修重复消耗真实模型；保留前批实际后端证据，不将其代替此次 UI 验收。
