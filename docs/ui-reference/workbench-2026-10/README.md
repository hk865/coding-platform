# 工作台新原型（2026-10-07 冻结）

**这是什么。** 新工作台界面的原型，是新界面（E3）移植时的界面基线。
- 用户 2026-10-05 批准原型（画布第 9 版）。
- 之后按 HANDOFF 决定 25–30、33 改版，并补了第 11 版的三处，用户都确认过。
- 2026-10-07 用户确认画布第 16 版后冻结（“可以冻结原型了”）。本目录就是第 16 版发布的文件，`SHA256SUMS` 可以核对。

**怎么看。** 画板文件（`*.dc.html`）要在 Design 画布里打开，它们依赖画布提供的 `support.js`，直接用浏览器打开不能完整显示。画布：https://claude.ai/artifact/3e5ynF3rwtMQfvJuim9mL2 ，只有用户本人能打开。

**本目录。**
- 10 块画板：主画面、方案选择与迭代、目标顺序与冲突、思维链、成员页、需要你决定、完成与交付、手机、任务图（整页）、完整架构图。
- `kit.css`：所有画板共用的样式。
- `canvas.json`：画布上画板的位置和标题。
- `DESIGN.md`：设计说明（英文），包括状态词、方格、颜色、组件、每次改版的记录和检查方法。
- `data/`：画板里逐字粘贴的共用代码和示例数据的源文件。画板里的副本和这里一致；`data/README.md` 说明哪块画板粘了哪份。

**示例数据不是产品数据。** 画板里的任务、成员、时间都是示例。移植时只照界面和交互，数据接真实后端；后端还没有的读取，按 STATUS“下一步”和编排设计补。

**以什么为准。** 界面以本目录的画板和 [UI-WORKBENCH §0](../../UI-WORKBENCH.md#ui-decisions-2026-10) 为准。`../agent-workbench.html` 只管 §0 没有替换的部分。被替换的点，不得按旧原型“纠正”回去。

**2026-10-07 冻结之后的修改。** 画板停在第 16 版，不再改。之后决定 37、38 改了几处：主对话是交互面，请求旁边写交给了哪个秘书；左栏“秘书”一组可以有几行；谁能在主对话上发卡；“已做完”和“已退役”分开；已做完的线可以直接干预。这些列在 UI-WORKBENCH §0 的“2026-10-07 冻结之后的修改”。画板和那一段说法不同时，以那一段为准。
