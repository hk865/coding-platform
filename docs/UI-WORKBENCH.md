### 新增

1. **主对话用于交互（Q1）。**
   - 主对话就是“秘书（主对话）”：你问，它回答。
   - 要下指令时，秘书给 2–3 个方案。你选一个，在对话里迭代，每一轮显示方案改了什么，满意了再采用。
   - 采用后，按该目标的自治级别开始工作。
2. **目标（Q2）。**
   - 每个目标一条对话线，一个项目可以有多个目标。
   - 目标有明确顺序，这需要新字段。
   - 界面提示目标之间的冲突，例如共享的文件或模块、影响路径。冲突提示**只是建议，不是闸门**，也不默认推荐“等待”：“等前一个目标 / 调整顺序 / 接受风险并行”三个选项并列。
3. **自治级别（Q3）。**
   - 按目标设置，默认「方案确认后自动」：确认目标卡和第一个方案后，细化、返工、重新检查都自动进行。
   - 改目标、验收或范围，超预算，以及上报，进入「需要你决定」。
4. **「需要你决定」（Q4）。**
   - 全局队列，分两级：要决定 / 请知悉；目标栏显示计数。
   - 打开一项，决定卡出现在输入框的位置；每张卡都有“问秘书”。
   - 默认不发浏览器通知。
5. **成员卡片（Q5）。**
   - 每张卡显示：角色 · 负责范围 · 状态词（工作中 / 等回复 / 待命 / 已暂停 / 待核对）。
