# 工作台 UI：已确认交互与真实接线边界

更新：2026-09-26。本文记录用户已确认的工作台方向；原型用于审阅交互，生产功能以 `coding-platform/next` 的真实入口和验收为准。[PRODUCT §8](PRODUCT.md#8-界面与信息组织)、[MVP B07](MVP-BEHAVIOR.md#b07查询解释与统一导航) 与 [R6 后续接线](refactor/tasks/R6-host-workbench-skeleton.md#67-下一批-ui先接真实浏览与草稿再接执行动作未派发) 共同约束实现，不新增后端 owner。

## 1. 已确认的 13 项方向

1. 左侧按项目组织 Agent；工作中、待命和其他未归档 Session 保持可找，归档按需打开，角色说明默认收起。Agent 名册沿原 Session/Role/工作关联，不另造永久主体目录。
2. 中心为传统 Session，可切项目主对话、指定 Agent 对话与行为观察。默认分段、摘要或折叠浏览；主动展开“原始历史/原始记录”后可查看该 Session 实际持久化的完整记录，包括已有 reasoningContent/reasoning、模型正文、工具原始参数和结果。摘要不替代原文，不因默认展示策略永久屏蔽字段；不生成解释冒充原记录。
3. Task 折叠与原序视图引用相同事件，保留真实事件顺序；并行活动不拼成单条因果链，无 Task 的查询也保留在原会话中。
4. 右侧为辅助工作区，可隐藏、放大、新建、切换和关闭多个页签。两条分隔可调；隐藏/恢复保留页签、草稿、选择和滚动位置，不停止实际工作。
5. 整体固定视口高度，对话、辅助子页和详情各自内部滚动；页签、主要操作和输入持续可用，长内容不撑高外页。窄屏时仍能定位当前对象和输入。
6. Task 与架构图都使用可见节点与连线；窄栏保留足够大的内部画布及横向滚动，不靠缩小文字塞满所有节点。
7. Task 使用时间从上到下的连续纵向放大镜，邻近区域连续展开，实际并行区间横向分列；离散轨迹另行保留。未来任务无执行时间时放在未来区，不伪造历史时间。
8. 架构包含树展开活跃节点到 root 的路径并集、相应兄弟和用户手动分支，更新不收起用户正在查看的分支；包含树与依赖 DAG 分开，不能从依赖边或文件路径猜模块父子。
9. 单击节点显示详情，hover 只给短预览；双击或右键可固定完整名称与状态。固定仅为显示偏好，不冻结业务状态或坐标；右键与详情支持在新 tab 打开，提供等效按钮/键盘入口。
10. 图详情关联既有 current/historical Agent、归档 Session、文件与 diff，沿完整身份和正确版本导航；缺失、未知、未授权、历史与确实为空分别表达。
11. 文件目录树与独立文件编辑 tab 分开；从对话、图或目录打开文件均进入辅助区，两者都支持加入当前对话草稿。同名文件按路径/作用域/版本区分。
12. 整文件引用带 path；选区引用带 path、片段与起止行。未保存内容标明“草稿快照”，不能冒充磁盘已保存版本；编辑与选区在切 tab 后保留。
13. 加入引用只修改当前 scope/对话 draft，不自动发送或启动模型；用户发送时才走原正式入口。归档 Session 只读，不向其发送，也不往归档页建立可发送草稿。

## 2. 原型复核与生产边界

**交互规范已加入网页原型**：三栏分隔线、Task 收纳/原序切换、按时长或轮次查看的 Session 轨迹、Task 结构/时序切换与局部查看窗、架构活跃路径及兄弟展开、节点悬停/右键、当前与历史 Agent（含归档）、文件和 diff 导航均有示例交互。跟随最新使用显式“模拟下一事件”演示，不代表真实执行订阅。

此前已核对键盘调宽、图节点详情、轨迹定位、右键菜单及 diff 新页，并修正详情展开因容器高度变化而重置。本次主代理在实际 Chromium 复核了左右指针拖动（左栏 180→280px、右栏 300→540px）、节点双击固定及新 tab、编辑切 tab 保留、隐藏/恢复后的文件页和草稿保留；操作期间外页高度保持 680px。选区加入草稿保留 `src/completion.ts:L1-L2`、片段与未保存标记，没有发送；归档页拒绝加入可发送草稿。证据：[操作结果](refactor/reviews/evidence/next-b2-2026-09-26/ui-prototype-next-review.json)、[截图](refactor/reviews/evidence/next-b2-2026-09-26/ui-prototype-next-review.png)。这些均为原型内存状态复核，不替代生产验收。


本轮原型演示：精简 Session、任务摘要折叠、项目/Agent 切换、按需角色说明、树状任务/架构、点选详情、右侧文件/终端、新建页、多页切换/关闭、整体显隐与放大。所有内容是示例数据，没有真实模型或命令执行。

## 3. 生产实现验收

生产实现须验收：

1. 默认无卡片墙、无常驻右侧详情；打开与关闭辅助区后中心能自然恢复宽度。
2. 任务摘要展开后才出现任务，点击树节点才出现详情；键盘同样可以操作。
3. 文件管理只在右侧，来自对话或 Agent 的文件引用也打开右侧页面。
4. 新建多个页面可分别切换和关闭；隐藏再显示保留当前页、节点、文件、滚动位置，不误停止任务/终端。
5. 同名文件、多个图范围和多个终端能区分，页签多时仍保持简洁。
6. Agent 工作中与待命者都保持可找，历史按权限可查；状态颜色有文字/可访问标签补充。
7. 查询、展开和页面切换不启动模型；长输出与大树按需读取，不全量重复刷新。
8. 窄屏、长标题、空状态、未知结果、浅深主题下无关键内容重叠，发送对象与项目范围准确。

新增验收场景：

9. 拖动两条分隔线能连续调整三栏，受最小宽度约束；放大/恢复后比例不丢，键盘可以调整，不触发数据重建。
10. Task 收纳和原序视图引用同一事件；跨 Task、无 Task 查询、并行工具和返工历史不被错误重排或伪造。
11. 极简图通过鼠标、键盘与触屏均可定位名称和状态；悬停不抢焦点、不取全量日志，右键动作有等效按钮入口。
12. 多活跃架构路径取并集，已展开兄弟保留；不把依赖 DAG 误画成包含树，不因状态更新收起用户正在看的分支。
13. 轨迹局部窗向下推进时，用户回看历史会停止跟随；未来任务不被安放在伪造的历史时间上。
14. 两图节点均能关联当前与历史 Agent，含归档 Session，并导航到正确文件/diff 版本；未知/缺失/未授权和确实为空分别表达。
15. Agent 查看页和交互 Session 均有主动展开原始历史的入口；默认不铺开长记录，展开后保留实际读取原文的全部字段和原始事件顺序，包括已保存的推理字段。仅拿到 ArtifactRef 时明确正文尚未读取，并沿原读取入口取得来源，不伪造完整内容。原文按文本安全渲染，保留分页和原记录身份。

真实接线仍见 [END-TO-END](refactor/skeleton/END-TO-END.md)，完成语义仍见 [MVP B06](MVP-BEHAVIOR.md)。原型尚不代替完整树懒加载、真实文件编辑、终端会话和持久布局验收。


## 11. 宽栏、连续放大镜与固定节点（本轮交互修订）

- 右侧宽度不再以 480px 为上限，可占用扣除左栏与最小对话宽度后的空间；放大视图仍可暂时收起中间。分隔线支持方向键、Shift 加速、End 扩至最大、Home 恢复。本次实际 Chromium 已核对左右指针拖动；生产与触屏行为仍须独立验收。
- 任务图与架构图保留足够宽的内部画布，受限时出现底部横向滚动条；横向查看位置按页面保存，不通过缩小文字塞入所有节点。
- Task 结构使用连续纵向焦点，时间由上向下推进；右侧竖条、滚轮和键盘移动放大镜，连续展开邻近区域的间距与名称。执行区间重叠的任务在不同横向分支同时出现；包含关系连线不等于调度依赖。无执行时间的未来任务留在独立区域。这里的时间、持续区间和并行任务均为演示数据。
- 离散轨迹视图继续保留，同一纵向时间位置允许多条任务轨迹；只在同一 Task 内连事件顺序，不把并行事件串成一条因果链。
- 单击节点选中并显示关联详情；双击或右键“固定完整显示”保持名称与状态，离开放大镜或切到极简也不消失。再次双击或右键可取消固定。架构图保留固定节点的祖先路径。固定只影响显示，不冻结业务状态或坐标。
- 详情提供“在新标签页打开”，右键提供同等入口，新页以节点名称命名。单击默认就地预览，避免探索节点时不断增加页签；原页面的焦点、横向位置和固定集合保留。

网页原型已演示以上行为；浏览器核对了连续焦点、固定标签、宽栏键盘调整和新页打开。生产仍需验证真实并发数据、长图性能、触屏拖动与跨尺寸布局恢复。

原型直接以 HTML 文件打开时缺少宿主提供的 `lucide` 全局，部分图标按钮没有图标但保留可访问名称。本次未改原型源码；生产使用随静态产物交付的图标或明确文字按钮，不依赖演示宿主全局。生产当前仍为表单/列表；架构包含关系、完整历史尝试导航、文件保存、真正模型发送与控制各按 R6 原 owner 接线，原型交互不能证明这些后端能力已交付。
